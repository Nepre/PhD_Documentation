# Thoughts

While it is an older paper (2009) it offers a good outlook on how a mixed technique terrain deformation solution could be done.

It is quite similar to the approach I had in mind: a 2 dimensional array of vertical columns.

The approach to use particles for surface soil is quite clever, so I will see if we can use it for our needs.
